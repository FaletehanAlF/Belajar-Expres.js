# Express.js Playground

Repository untuk belajar dan mencoba dasar-dasar **Express.js** dengan TypeScript dan Node.js.

## Materi

* Express.js
* TypeScript
* Routing
* REST API
* HTTP Method
* Request & Response
* CRUD dasar

## Setup

```bash
npm install express
```

Jalankan project:

```bash
npm run dev
```

## Status

🚧 **Learning / Playground**

Project ini masih dalam tahap pembelajaran dan akan dikembangkan secara bertahap.
